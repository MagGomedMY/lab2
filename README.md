## Задание 1. Вариант 4

**Условие:**  
1. Запросить `n`, создать вектор из `n` целых чисел.  
2. Используя итераторы, найти минимальный и максимальный элементы.  
3. Поменять их местами.  
4. Вывести изменённый вектор.

**Реализация:**
- Считываем `n`, создаём `std::vector<int> v(n)`.
- Заполняем вектор через цикл.
- Создаём итераторы `minIt` и `maxIt`, инициализируем `v.begin()`.
- Проходим итератором по вектору, обновляем `minIt` и `maxIt`.
- Меняем значения через `std::swap(*minIt, *maxIt)`.
- Выводим вектор.

**Пример ввода:**
```text
5
3 7 1 9 4
```

## Задание 2. Вариант 4

**Условие:**  
Написать функцию `repeat`, принимающую вектор `v` и неотрицательное целое `n`, и возвращающую новый вектор, полученный повторением `v` `n` раз. Определить количество пар элементов, для которых:
- последняя цифра одного = предпоследней цифре другого;
- ровно один элемент делится на 11;
- сумма квадратов пары ≥ квадрата среднего арифметического элементов, у которых две последние цифры одинаковы.

**Реализация:**
- Функция `repeat` копирует вектор `v` `n` раз в новый вектор.
- Считаем среднее арифметическое всех элементов.
- Отбираем элементы, у которых две последние цифры одинаковы.
- Перебираем все пары, проверяем три условия.
- Считаем количество пар и максимальную сумму квадратов.

## Пример ввода

Введите количество элементов исходного вектора: 3
Введите 3 целых чисел: 11 22 33
Введите число повторений k: 2
